## Text Elements
uefi:
function: 
*its a firmware which is loaded onto cpu
*does system check , read from nvram and executes efi 
* reads storage partitions (gpt,mbr) and initial sector of all , which help nvram to find the file location
location: in a spi flash chip ^3myc4I8l

gpt:
function:
*it is just a rule / scheme for the ssd to store contents
* has sectors as a fundamental storage block , with per sector size 512 bytes 
* 64 bit adress system for labelling sectors . so total of 2^64 address are possible.
*notes:
0 Protective MBR  1 Sector
1 Primary GPT Header  1 Sector
2-33 PartitionArray  32 Sectors
34 - 2047 Unused 2014 Sectors
2048 Start of Partition (sdx1)
*it is default but can be modified
*has the copy of the first section at the end
location:the first section of ssd ^4l28tbvg

nvram:
function:
* memory for uefi
* boot entries for efi ( but the path given by gpt )

location:
motherboard ^wh70DGaP

.efi:
function:
*has a pointer for grub.cfg 
*is an executable run by uefi
location: specific for os , .efi is usally inside a fat32 partition ^HX6lz4q5

.cfg:
function:
* pointer to kernel images
* the main grub configuration
location: 
/boot/grub/grub.cfg ^3Db7SAr6

commands:
grub-install  : helps to create the entire efi partition from scratch / modify on an existing  fat32 , 
grub-mkconfig : modify grub.cfg
efi-bootmgr: change bootorder ^O9a1Qgmg
