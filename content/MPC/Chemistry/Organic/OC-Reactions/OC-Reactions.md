# Reactions
## hoffman bromamide 
![hoffman bromamide ](Assets/OC-Reactions/1768633531.png)
isocyanate intermediate $R-N=C=O$     
**Reaction:**  
$$\ce{R-CONH2 + Br2 + 4OH^- -> R-NCO + 2Br^- + 2H2O + 2OH^-}$$
$$\ce{R-NCO + H2O -> R-NH2 + CO2}$$

**Mechanism:**  
1. **Bromination:**  
   $$\ce{R-CONH2 + Br2 + OH^- -> R-CONHBr + Br^- + H2O}$$  [deproto happens first]
2. **Deprotonation:**  
   $$\ce{R-CONHBr + OH^- -> R-CONBr^- + H2O}$$  
3. **Rearrangement (Migration):**  
   $$\ce{R-CONBr^- -> R-NCO + Br^-}$$  
4. **Hydrolysis:**  
   $$\ce{R-NCO + H2O -> R-NH2 + CO2}$$
## hvz
![hell_vol_zel](Assets/OC-Reactions/1768672822.png)

**General Reaction**
$$\ce{R-CH2-COOH ->[X_2, \text{red } P][H2O] R-CH(X)-COOH}$$
### Mechanism

**1. Catalyst Formation**
$$\ce{2P + 3X2 -> 2PX3}$$

**2. Formation of Acid Halide**
$$\ce{R-CH2-COOH + PX3 -> R-CH2-C(=O)X + H3PO3}$$

**3. Tautomerization**
$$\ce{R-CH2-C(=O)X <=> R-CH=C(OH)X}$$

**4. Halogenation**
$$\ce{R-CH=C(OH)X + X2 -> R-CH(X)-C(=O)X + HX}$$

**5. Final Exchange**
$$\ce{R-CH(X)-COX + R-CH2-COOH -> R-CH(X)-COOH + R-CH2-COX}$$
